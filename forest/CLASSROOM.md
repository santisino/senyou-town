# 百蚂村 · 懂我与合拍演示指南

版本：connections-v2，2026 年 10 月 7 日。

演示地址：https://santisino.github.io/senyou-town/forest/?v=connections-v2

## 最短演示入口

1. 网站顶部直接点「教学主持台」，首次选择「活动村长演示身份」。
2. 点「演示准备」→「准备样本并开放发现伙伴」。
3. 点「作为小禾去公告栏」；人物会沿路走过去，抵达后翻开居民名册。
4. 看小林的懂我卡：点亮、问候、建议、心愿、合拍预览与协作邀请都在这里。
5. 顶部「教学主持台」→「课堂进程」→「协作任务」，发布后再到教室作答。
6. 「班级大屏」看统计与协同观察；「班级合拍地图」看自愿参与者的公开连接。

开场仍然是森林，不自动弹表单；普通参与者仍须走到村长、小屋和具体物件再互动。主持台是显式的演示/主持入口，不替代游戏探索。

## 完整体验

### 1. 个人表达与村民卡

不使用报告也可以完成入驻。与村长对话、领取宅地、走到工具箱搭建基础小屋；在门牌、兴趣角、会客桌、心愿瓶表达自己，最后到册子亲自确认。

确认后再次点册子，领取村民卡。称号由本人选择，不按 DISC 高低判断能力。三种文风采用本地规则整理公开内容，并非调用 AI 模型。形象与小屋沿用既有 Blender 资产，不以概念图替代运行成果。

电脑点「下载 PNG」。手机可点图片打开原图后长按保存，或使用浏览器支持的系统文件分享。不支持文件分享时会提示替代路径。长内容为节选，以图片预览为准；完整内容仍在小屋。二维码进入公共村独立体验，不上传个人资料。

### 2. 补充连接线索

册子或自己的懂我卡 →「补充连接线索与偏好」。

可选填写工作经验、想学习的事、想讨论的困惑，逐项决定是否在当前村公开。它们进入同一份个人资料，同时用于册子、会客桌、懂我卡与撮合，不另存一套自我介绍。

协作偏好可以自述，也可主动带入一份虚构 DISC 建议；未勾选本人确认不会保存。必须另外允许本村公开，才能参与偏好撮合。不能根据未公开报告或否定表达推断人格。

在这里也设置点亮、建议、匿名建议、地图参与、地图具名以及成长阶段的公开范围。反思正文始终不随成长阶段公开。

### 3. 发现与互动

在公告栏先找人，再沿路去小屋。懂我卡的每类内容都有下一步：兴趣找同好、心愿表达兴趣、学习内容留建议、协作提示生成可改写的问候。

对方从自己小屋信箱、懂我卡「森林消息」或教室收到本机回应。心愿继续沿用人数上限、最多同时参与 3 条、申请/同意/拒绝/撤回的原有规则。点亮、收礼、申请任务均不自动交换联系方式。

匿名建议仅在接收者界面隐藏名字，本地存储不是安全匿名服务。只有主人开启接收匿名建议，发送方才能选择。

### 4. 合拍任务

懂我卡底部「邀请一起做协作任务」始终有明确状态：可邀请、已有任务、等待开放、当前复盘或公共村不办课堂，不再静默隐藏。

接受邀请 → 主持人发布任务 → 双方独立选择 → 双方都提交后看理由 → 对照公开协作偏好讨论 → 写约定 → 双方确认。

公开偏好与情境选择不必一致，复盘询问“这次有什么条件改变了我的决定”，不把一次选择判为某种人格。

虚构搭档需主动点击「模拟搭档……」才能响应。约定改动会清除旧签名和分享授权。双方授权当前内容后，可下载原有双人协作成果卡。

### 5. 班级地图与观察

地图不是人格匹配率：绿线表示公开信息中的连接线索，棕线表示已完成合作。至少 3 位确认说明书并自愿参加后展示；默认编号，可另选具名，撤回后节点与相关连线消失。

手机上的图可以横向滚动，下方提供同筛选条件的文字清单。去标识仍可能被熟悉同学的人识别，不能当作严格匿名保证。

班级大屏只汇总主动授权的情境选择。少于 3 份不生成观察。总结引用真实本机计数、并列情况和任务完成记录，给出讨论与下次练习，不声称学习效果或团队能力。

演示准备可以补充空闲虚构组合及示例授权，跳过已有任务和已接管角色，不覆盖真实输入；不会再自动切到复盘而隐藏邀请。

### 6. 课后回访

双方确认约定后，在各自的成长叶保留。每次记录追加在时间线上，重复点击同一条不会重复保存，不覆盖旧实践。可以记录“有帮助”“还要调整”或“还没试”。

「预览一周后的回访」只是展示未来状态，不修改日期，不伪造实践，不设置自动推送。回顾后可以亲自改写、确认是否公开协作介绍，各处随同一资料同步；不自动把私密反思变成标签。

个人资料和成长叶跨村保留。新村的公开范围、地图与报告授权独立，原村社交、课堂消息和申请不会带到公共村。

## 教学与演示的边界

- 教学主持台每次从「课堂进程」打开；45 分钟和紧凑 30 分钟仅为主持参考，不自动切换。
- 旧「开放串门」与课堂发现阶段已同步；旧的已开放存档也能进入发现伙伴。
- 完成个人表达不是完成专业测评。教室可自报“未开始 / 示例 / 已完成待核验 / 不使用”，主持台明确区分。
- 第一阶段仍需要本人完成并确认说明书；没有擅自改成无需填写就能浏览全村。
- 公开小屋仍可串门，没有擅自改成完全私有小屋。

## 重演与资料保护

- 只重启课堂：教学主持台 → 演示准备 → 开始新一轮课堂 → 二次确认。清除本轮任务、问候、课堂授权；保留说明书、成长叶和独立的点亮/建议历史。
- 重新准备虚构居民：不清除真实填写内容；已接管虚构角色的新增资料不会被样例覆盖。此时可在该角色的个人设置中亲自补充公开范围。
- 完全重置仍从原有「演示者」执行，会清除新版所有测试状态，执行前须看清确认说明；旧站数据不受影响。

## 实现与验收边界

本次是本机可操作 Demo：无企业登录、专业 DISC 解析、AI 服务、跨设备消息、实时多人班级、真实自动课后提醒或安全后台。所有权限与隐私是界面/状态规则，不代表服务端隔离。不要输入真实员工敏感资料。

规则测试：`node --test forest/tests/*.test.mjs`。浏览器验证覆盖实际走路到公告栏与小屋、双方任务确认、PNG 下载、刷新恢复和手机尺寸布局。手机尺寸/触控模拟不等于真机微信浏览器验收。

- `connect-data.js`：个人身份、公开线索、七维推荐、偏好预览、地图、协同观察、成长记录规则。
- `connect-ui.js` / `connect.css`：村民卡、可保存图片、懂我卡互动、关系图、成长回访。
- `lesson-data.js` / `lesson-ui.js`：原有课堂状态、任务与新功能入口。
- `state.js` / `villages.js`：统一事务、旧状态兼容和跨村数据范围。
- `app.js`：真实场景物件、信箱、册子与新功能联动。
