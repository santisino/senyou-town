# 百蚂村 · 合拍局演示指南

版本：classroom-v1，2026 年 10 月 5 日。

演示地址：https://santisino.github.io/senyou-town/forest/?v=classroom-v1

## 这一版讲清楚什么

一个人先在森林里表达自己，发现一个想认识的伙伴，通过一次具体协作看见彼此的关注点，再带走双方确认的约定。课堂结束不是清空个人资料；自己愿意保留的成长记录，可以延续到公共村。

森林仍是入口：开场不自动弹课堂表单。人物可走动、沿路寻路、旋转缩放视角。只有主动进入公告栏、教室或小屋物件，才出现对应内容。教学主持台是演示者和班主任使用的管理界面，不替代玩家的探索过程。

## 给客户演示，建议按这条顺序

### 1. 准备课堂

1. 打开网站，点击顶部「村长工作台」。
2. 选择活动村长或「东来：活动村＋公共村」的演示身份。若当前在公共村，先从村庄选择器回到百蚂活动村。
3. 点击「打开教学主持台」，切到「演示说明」。
4. 点击「准备虚构居民小屋」。这只准备样本，不替“新森友”填写个人说明书。
5. 在「课堂进程」点击「开放发现伙伴」。此前已完成个人表达的居民才可以互相看介绍；未完成者仍需完成自己的表达。

也可从「演示者」→「打开教学主持台」进入，显式选择管理身份。

### 2. 作为小禾认识小林

1. 主持台「演示说明」中点击「作为小禾走到公告栏」。人物会沿路行走，抵达公园后再出现内容。
2. 翻开居民名册，打开小林的「懂我卡」。卡片内容来自他在小屋确认的公开介绍，不是另写的一套资料。
3. 可以按共同兴趣、心愿或正在探索的事找连接点；规则推荐不是 DISC 合拍率。
4. 点击「沿路去他家坐坐」，探索兴趣物件、会客桌、心愿瓶和《小屋里的我》。会客桌也能再次打开懂我卡。
5. 在懂我卡发出协作邀请。点击「模拟搭档接受邀请」，明确展示对方的同意步骤。也可用演示角色切换，由另一个本机角色亲自回应。

### 3. 完成一次真实可操作的协作流程

1. 回「教学主持台」的「课堂进程」，发布协作任务。
2. 返回森林，按提示沿路走到教室，打开自己的协作任务。
3. 可先记录一个私密课前问题，自主决定是否将本次选择计入班级匿名分布。
4. 读「还有 30 分钟，要不要上线？」的情境。独立选择一个处理起点，可补充自己的理由。
5. 主动模拟搭档作答。双方都提交后，才互相看到选择与理由；看不到另一方尚未提交的答案。
6. 根据讨论提示，写一条明确的协作约定，例如检查范围、谁来记录、何时同步。先保存草稿。
7. 双方分别确认。改动已保存的约定会清除旧确认，需要重新取得双方同意。

没有人格标准答案、能力排行或“低分需要补足”的结论。讨论提示是预设规则，不是调用了真实专业报告。

### 4. 分享与复盘

1. 共同确认不等于授权分享。双方再分别同意分享当前版本，才能预览和下载双人协作成果卡。
2. PC 点击「下载 PNG」。手机可使用系统文件分享（浏览器支持时），或打开原图长按保存；不支持系统分享时会提示替代方式。
3. 图片只包含双方称呼、选择标题和共同约定，不包含原始报告、私人理由或联系方式。二维码进入公共村，不上传双方资料。
4. 双方可撤回生成新图片的授权，但已经保存、发送到其他设备的文件不能远程撤回。
5. 班主任打开「班级大屏」，查看准备人数、小组数、完成数，以及主动授权选择的去标识分布。少于 3 份有效授权选择时不显示分布。
6. 演示说明中可以生成可用的虚构结果组合，预览图表。此操作会明确生成示例投屏授权，跳过已有任务和已接管的示例角色，不为真实用户代填。

### 5. 把收获带到课后

1. 双方确认后，共同约定进入各自的「课后成长叶」。
2. 从教室或成长林打开，记录一次真实尝试、遇到的困难或下次想调整的地方。
3. 去蚂蚁森友村继续探索：个人介绍不重填，但新加入者仍须主动确认公共村加入与公开范围。预置虚构常住居民已在公共村中。
4. 成长叶跨村保留，保持私密；不会被自动写成公开标签、同步给班主任或显示在其他人的懂我卡中。

## 如何重演

- 只清本轮课堂：教学主持台 → 演示说明 → 开始新一轮课堂 → 二次确认。清除当前村课堂邀请、作答、问候和授权；保留个人说明书和已共同确认的成长叶。
- 完全重新体验：原有演示者控制台 → 从空宅地重新体验。会重置新版 Forest 测试状态，包括各村与成长记录；历史旧站存储不受影响。请先下载要保留的成果。
- 角色切换和章节跳转属于本机演示工具，不是正式账号授权。不要在 Demo 输入真实员工敏感资料。

## 数据与正式开发边界

| 本次实际实现 | 本次不声称已实现 |
| --- | --- |
| 本浏览器中可持续保存的资料、阶段、邀请和双人状态 | 跨设备实时班级、真实 50/100 人并发 |
| 分步同意、内容修改后确认失效、各村展示范围 | 服务器安全隔离、企业 SSO、真实权限系统 |
| 基于公开表达的规则推荐与情境讨论提示 | 专业 DISC 解析、匹配评分、调用真实报告 API |
| 本地生成可下载 PNG，二维码承接公共村入口 | 上传真实资料、跨设备访问刚生成的个人小屋 |
| 本机参与进度与授权汇总，可显式生成虚构样例 | 企业真实学习成效、业绩提升或班级数据分析 |
| 成长叶私密回顾与跨村保留 | 自动人格成长判断、健康诊断、员工绩效评估 |

个人原始资料、课堂记录实际都存于同一个浏览器。本次的“私密”指界面与状态规则上的访问范围，并非具备服务端隔离的安全保证。正式产品需由蚂蚁技术团队实现认证、鉴权、存储、同步、审计与分享撤销。

## 开发交接

- `lesson-data.js`：村内课堂状态、配对、分步同意、公开投影、规则推荐、去标识汇总与跨村成长叶。
- `lesson-ui.js` / `lesson.css`：班主任主持台、学员任务、懂我卡、成长叶、投屏视图与 PNG 导出。
- `state.js`：统一事务入口、持久化与村庄投影；追加字段而非替换旧存储键。
- `app.js` / `village-ui.js`：把新流程接入已有森林、物件与村长工作台。
- `tests/lesson.test.mjs`：课堂状态、权限边界、授权失效、保存恢复和跨村隔离测试。
- 沿用已有 Blender 工程和导出模型，本轮没有另建一套视觉资产或用效果图替代运行网页。

在仓库根目录执行 `node --test forest/tests/*.test.mjs`；使用普通静态服务器运行网站，无需构建，也无需新增付费接口。
