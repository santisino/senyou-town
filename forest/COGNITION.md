# 私人认知体验 · cognition-v1

同一间小屋保留待客区，并增加右侧屏风后的私人认知区。参与者在场景中走近物件后才打开内容；载入报告不是完成入驻的前提。

## 七项与实现位置

| 产品架构 | 实际物件与操作 | 保存与边界 |
|---|---|---|
| 小屋外观：DISC 四维、灰度光谱 | 小屋风格配方；四条“像我的程度”滑杆；实际户外瞭望装置、交流桌、绿植与工艺台改变大小，屋顶比例和颜色变化 | 原始样例不变，混合风格单独保存。不是强制四项合计 100% 的人格分配 |
| 三扇窗：自然、工作、压力 | 晨光森林、工作市集、柔和风雨的 Blender 浮雕；走近并推窗；三状态四维对照；写个人情境 | 风暴窗先提醒、本人主动开启；笔记不进入公开介绍 |
| 16 本行为书 | 16 本独立 Blender 书籍；核心、次要、阴影和压力；逐本读故事，判断像不像，写例子，翻正阴影书 | 两本压力书需主动开启风暴窗；不是把全部词强加给用户 |
| 双面门牌 | 私人区门牌内面保存优势、练习与协作建议；分享出口确认后同步外面 | 公开门牌、会客桌、懂我卡和册子读取 `profile.collaboration`；没有另一套公开文案 |
| 壁炉镜子 | 按样例选择三道面谈问题，写具体经历、1–10 自评和下次提醒；规则反馈引用本人回答 | 不是在线心理评估或 AI 面谈；分数是本人自报贴近程度，不是客观认知准确率 |
| 阳光系统 | 四束光分别可以走近，调需要程度、关灯体验、汇总光源配方 | 底部光圈和真实 Three.js 点光源随开关变化；保留基础照明；主动选一句分享 |
| 合拍实验室 | 同村已入驻伙伴→单独来源授权→成分对照→反应皿→协作处方→最多五次自报实践→PNG | 五类反应图鉴独立标注，不改写两人规则对照。五次不等于“治好”。单方分享不带伙伴姓名、成分或私密记录 |

先完成公共表达和本人确认；私人区 1–6 可在开放前探索；第 7 项在开放串门、存在合适同村伙伴后完成。另一入口是邻居懂我卡底部“到我的合拍实验台探索”，人物沿路回自己小屋，预选该邻居，但仍须本人确认来源。

## 资产与源文件

- `source/build_cognition.py`：复用既有 Blender 几何工具和暖木材质，制作私人翼与外观元素。
- `source/cognition.blend`：真实可编辑 Blender 工程。
- `assets/cognition.glb`：Draco 压缩导出模型。所有交互物件有稳定组名，不把中文内容焊进网格。
- `assets/cognition-manifest.json`：导出物件清单，16 本书、3 扇窗、4 束光。
- `cognition-data.js`：三份明确虚构的作者样例、私人数据、校准及权限与状态规则。
- `cognition-ui.js`、`cognition.css`：物件触发的阅读、表达、授权、导出界面。
- `world.js`：实际行走、家具避障、私人区进出、原生射线点选和物件反馈。
- `tests/cognition.test.mjs`：新增隐私、授权、原始样例不变、持久化及互动状态测试。

重新导出（需要本机 Blender）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python forest/source/build_cognition.py
```

## 数据约束

`network.cognition[personId]` 跟人走，不进入村庄居民公开投影。`cognitionConsent` 和 `cognitionPublication` 跟村庄成员记录走；公开范围不会因换村自动继承。发布只替换 canonical `profile.collaboration`，只改本村这一项公开开关。

本次没有真实员工资料、真实 DISC 解析、专业兼容性模型、联网 LLM、服务器账号或跨设备同步。私人分区与权限是本地 Demo 展示边界，不是安全后台；本机存储能被开发者工具读取，不能用于保存真实员工敏感报告。

## 待修改项

村庄类型与实际名称分开：顶部、村庄选择、村长工作台、邀请页使用“场景村｜百蚂村”“公共村｜蚂蚁森友村”；自建村同样使用“场景村｜实际名称”。NPC 仍自然使用实际村名。村庄 ID、加入规则与分享承接不改动。

## 与架构文档的有意区别

本次遵守已确认的“待客区＋私人区＋主动分享”约定，不把原先已认可的访客小屋改为完全禁止串门。外观保留原有暖木微缩底模，用四类真实元素表达主次混合，并未制作四个地理位置不同的完整大场景。面谈与合拍建议为可核对的作者规则样例，不冒充已接入真实报告引擎；三次、五次实践只改变视觉并保存自报记录，不自动宣布关系改善。
