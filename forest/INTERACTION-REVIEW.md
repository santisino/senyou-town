# 2026-09-28 场景交互修订

本次修订保留 Blender 资产与配色，改变的是游戏的操作逻辑。普通玩家与演示者章节跳转分开。

| 原入口 | 修订后的普通玩家行为 |
| --- | --- |
| 自动欢迎弹窗 | 玩家直接站在森林里；走近村长才开始对话 |
| 准备小屋按钮、连续四页填写 | 向村长报上称呼并领取钥匙；到自己的门牌、兴趣角、会客桌、心愿瓶分别表达 |
| 填完立即进入下一页 | 保存一处后合上面板，回到可走动的房间 |
| 远程完整说明书按钮 | 走近桌上的册子；四处布置完成后才可确认入驻 |
| 地图/名单立即切换小屋 | 先选择目标，再沿实际路线走到门口；名单已读过介绍时不重复门牌预览 |
| 手机物件快捷栏 | 点击场景中的物件标签后走过去，或使用摇杆靠近再互动 |
| 远程礼物信箱、送礼按钮 | 走到屋内信箱处理；从其他物件点“留礼物”也会先合上面板、走过去 |
| 公共空间菜单瞬移 | 步行到对应地点；回顾、收藏、报名等操作留在当前场景 |
| 屋内远程商店 | 先走到门口出门，再沿路去实体森林小铺 |

移动方式：WASD / 方向键、手机摇杆、点击地面或实体目标寻路。手动操作会取消自动寻路。俯瞰地图只改变镜头，不改变玩家位置；返回脚下后可以继续走动。只有演示手册中明确的章节跳转可以快速切换场景。

本地数据保持 `senyou-forest-demo-v1`，新增每位居民的 `journey` 进度。既有已完成资料保留完成资格；修改为空时不会丢失自己的钥匙。旧版网站、旧版存储与 Blender 工程均未覆盖。

## 本地验证

- 27 项 Node.js 规则测试通过，包含“只填资料不能绕过村长与四处布置”、旧居民兼容、全部屋内交互点之间的避障路径。
- 独立 Chrome 浏览器 39 项检查通过：首次进入、实际寻路、手动接管、村长对话、四处表达、册子、串门、心愿、礼物、公共空间、刷新恢复、手机入口及触控交谈。
- 实际视口：1440×900、390×844、360×800。手机为视口/触控模拟，不是真机验收。
- 最终本地 10 秒连续渲染采样约 60 FPS，不等同于 30 分钟稳定性测试。
- 最新测试记录：工作区 `output/森友会-新版交付/gameplay-local/result.json`。线上复验使用相同脚本，记录在 `gameplay-online/result.json`。

真实功能是本机行走、物件交互、资料和社交状态。人物间响应仍靠明确的演示角色切换；没有跨设备实时多人、真实 DISC 解析或后台权限。
