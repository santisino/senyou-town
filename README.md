# 森友小镇开张日

Blender 原创微缩场景 + Three.js 交互体验，静态部署在 GitHub Pages。

## 怎么体验

- 一个人：点「独自体验」，完成形象和 24 道问答，再确认自己的档案。预设邻居均明确标注为模拟角色。
- 一起玩：主持人点「主持人开场」，把邀请链接或场次码发给参与者。每人独立打开并完成入住。
- 主持人依次开放「串门」「共建」「开张」。参加者只能修改自己的资料，不能控制阶段。
- 共建项目先保存讨论稿，由另一位实际成员确认，再共同提交。修改稿件会使旧确认失效。
- 可以在门牌认识彼此，在档案袋了解习惯，在会客桌讨论合作，在信箱留下消息和约定。
- 开张后可修订自己的说明书、记录发现、下载带场景图的居民卡。

## 实时场次的边界

多人场次采用 PeerJS 1.5.5 信令和 WebRTC 数据连接，主持人浏览器是场次中枢。**主持人必须保持页面和网络在线**；这不是全天候云端服务。现场企业网络可能限制 WebRTC，请正式培训前用实际设备试连。代码设置 60 人上限，但不意味着已经完成 60 人并发实测。

场次存于主持人本机，可用「恢复上次主持的场次」恢复。参加者离线时，主持人可保管消息；参加者使用同一浏览器重连原场次后可看到。清理站点数据会清除本地身份和资料。多台设备之间不自动迁移身份。

每 12 间小屋组成一个可切换的街区。行动榜统计公共项目参与和交付，不评价人格、能力或受欢迎程度。

## 内容与隐私

题目参考 DISC 报告的沟通、行为偏好、信息需求、角色协作、困难应对等主题，属于原创自我探索题，**不是供应商 DISC 原题或经验证量表**。结果是本人确认的自述，不输出专业类型、能力分、心理健康诊断或合拍百分比。

原始答题只保存于本人浏览器。只同步本人确认分享的档案；支持需求默认不分享。未开放街区前，不向其他参加者同步个人档案正文。留言和合作约定只向双方呈现，但主持人作为数据中枢可以接触场次数据。请使用昵称，不填机密、联系方式和不愿分享的内容。项目方案和参与名单属于本场公开内容。

未将原报告、真实姓名、电话或报告链接放入项目。蚂蚁森林的合种、树友、梭梭/胡杨、物种观察等只作为文化与场景启发。游戏能量不等同于真实绿色能量、碳减排或公益捐种；本体验不代表蚂蚁森林官方产品。

## 运行与文件

使用任意静态服务器，例如 `python3 -m http.server 8777`，打开本地地址。无需构建。

- `opening-content.js`：题目、报告主题映射、说明书和公共项目内容。
- `opening-session.js`：主持端校验、阶段、私信、共同确认、实时同步。
- `opening-world.js`：场景、相机、形象与房屋点缀、街区和设施显现。
- `opening-app.js` / `opening.css`：界面、流程和居民卡导出。
- `assets/opening-day.glb`：Blender 导出的新场景。
- `assets/resident-v2.glb`：Blender 角色模型。
- `source/build_opening_day.py`：可复现的小镇建模、GLB 压缩导出和预览渲染脚本；通过 `blender --background --python source/build_opening_day.py` 运行，源场景和预览保存在 `build/opening-day/`。
- `vendor/PEERJS-LICENSE.txt`：PeerJS MIT 许可。

无 API 密钥、付费接口和第三方分析埋点。
